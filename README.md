# OpenTheZIP

**Ультрасовременный архиватор с собственным алгоритмом сверхсжатия, автономным шифрованием и встроенным файловым проводником.**

Сжимает файлы в 40–50 раз на избыточных данных, поддерживает парольную защиту папок и архивов, использует надёжные криптографические стандарты.  
Интерфейс в стиле «старой школы»: белый фон, шрифт Courier, классические иконки.

## Основные возможности

- 🗜 **Собственное сжатие LZMA2** – уровень 0–9 + экстремальный режим.
- 🔐 **AES‑256‑GCM шифрование** – ключ из пароля через PBKDF2 (200 000 итераций).
- ✅ **Контроль целостности** – каждая запись проверяется по SHA‑256.
- 📁 **Файловый проводник** – дерево каталогов с операциями создания, удаления, переименования.
- 🔒 **Защита папок паролем** – файл `.otz_lock` в скрытом виде (только через ввод пароля).
- 🔍 **Поиск по подстроке** в текущем каталоге.
- 📥 **Импорт/экспорт файлов** между папками.
- 🧩 **Расширенный выбор форматов** – `.otzip`, `.otz`, `.otzipx`, `.pzip`, `.arc`, `.zpaq`.
- ⚙ **Настройки сжатия** – меняются «на лету».
- 📄 **Диалог «О программе»** – лицензия MIT, политика конфиденциальности, сертификаты, ссылки на сайт и GitHub.

## Установка

Требуется **Python 3.9** или новее.

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ваш_логин/OpenTheZIP.git
cd OpenTheZIP
Установите зависимости:

bash
pip install -r requirements.txt
Запустите:

bash
python OpenTheZIP.py
Сборка в один исполняемый файл (Windows)
bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=icon.ico OpenTheZIP.py
Файл появится в папке dist. Иконку можно заменить на свою.

Использование
Проводник – перемещайтесь по папкам двойным кликом. Защищённые папки потребуют пароль.

Тулбар – быстрые кнопки «Домой», «Вверх», «Создать папку», «Удалить», «Переименовать».

Адресная строка – введите путь и нажмите Enter.

Сжатие – выберите файл → кнопка «Сжать» (или меню «Действие»). Введите пароль (опционально), выберите расширение.

Распаковка – кнопка «Распаковать» → выберите .otzip (или другой) архив → укажите папку.

Защита папки – правый клик по папке → «Защитить паролем…» → введите и подтвердите пароль.

Снять защиту – правый клик по защищённой папке → «Снять защиту паролем…» → введите текущий пароль.

Настройки → «Сжатие…» – уровень 0‑9 и экстремальный режим.

Технические детали
Формат архива: пользовательский заголовок с магией OTZP, версией, флагами шифрования, контрольной суммой SHA‑256.

Шифрование: AES‑256 в режиме GCM (аутентифицированное), ключ формируется по стандарту PBKDF2‑HMAC‑SHA256.

Сжатие: библиотека lzma (алгоритм LZMA2) с настройками preset и PRESET_EXTREME.

Интерфейс: PyQt5, модель QFileSystemModel, многопоточность (сжатие не блокирует окно).
